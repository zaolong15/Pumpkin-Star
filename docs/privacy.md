**最后更新：2026 年 2 月**

Pumpkin Star（以下简称"本扩展"）是一个运行在 Microsoft Edge / Google Chrome
浏览器中的 AI 网页智能体扩展，通过自然语言指令帮助用户读取、操作和改造网页。

本政策说明本扩展会接触哪些数据、这些数据去哪里、以及你如何控制它们。

**一句话总结：本扩展没有自己的服务器。你的数据要么留在本机，要么直接发往
你自己配置的 AI 模型服务商。开发者无法访问你的任何数据。**

---

## 1. 我们不收集什么

先说明最重要的一点——本扩展**不做**以下任何事情：

- ❌ 不收集浏览历史、访问过的网站列表
- ❌ 不包含任何统计分析、埋点或遥测代码（无 Google Analytics、Sentry、PostHog 等）
- ❌ 不向开发者或任何第三方服务器回传数据
- ❌ 不出售、出租或共享用户数据
- ❌ 不用于广告投放、用户画像、信用评估或任何信贷决策
- ❌ 不在后台自动浏览网页或自动发起任务

本扩展**没有自建后端服务器**。除了你主动配置的 AI 模型服务商之外，
它不与任何服务器通信。

---

## 2. 本扩展会接触哪些数据

### 2.1 你配置的服务信息（本地保存）

在设置中填写的以下内容，保存在浏览器的本地存储（`chrome.storage.local`）中：

- API 地址（Base URL）
- API 密钥（API Key）
- 模型名称、温度、最大步数等参数
- 外观偏好（主题色、深浅模式、图标选择等）

**这些内容仅存于你的设备**，只在调用 AI 模型时作为请求头发送给
**你自己填写的那个服务商**。开发者无法看到。

### 2.2 网页内容（仅在你下达指令时读取）

本扩展的核心功能是"看懂网页并替你操作"。为此，当你发送任务时，它会读取
**当前活动标签页**的以下内容：

- 页面的可交互元素清单（按钮、链接、输入框的编号与文本）
- 页面正文纯文本
- 页面结构骨架（区块标签、class 名、位置尺寸）

**关键说明：**

- 这些内容**只在你主动发送任务时**才被读取。
  扩展被注入到页面后不会自行读取或上传任何内容。
- 读取到的内容会随你的任务一起发送给你配置的 AI 模型服务商，
  以便模型理解页面并给出操作指令。
- 扩展不会读取其他标签页的内容。

### 2.3 剪贴板（仅在你主动点击时）

- 点击侧边栏的**剪贴板按钮**时，扩展会读取剪贴板文本作为任务上下文。
- 让 AI "复制给我"时，扩展会把结果写入剪贴板。
- 扩展**不会在后台读取剪贴板**，也不会监控剪贴板变化。
- 首次读取时浏览器会弹出权限提示，你可以拒绝。

### 2.4 你附加的本地文件（仅在你主动选择时）

- 点击**回形针按钮**选择文件后，扩展会读取该文件内容作为任务上下文。
- 扩展**无法自行访问你的磁盘**，必须由你在系统文件选择框中主动选择。
- 文件内容同样会随任务发送给你配置的模型服务商。

### 2.5 对话记忆与自进化内容（本地保存）

为提供连续性和"自进化"能力，扩展会在本地保存：

- **记忆**：你的偏好、事实、站点操作经验
- **技能**：从任务中总结的可复用方法
- **规则**：从执行过程中总结的自我提醒
- **用量统计**：token 数量、费用估算、任务历史

**这些内容全部存于本机**，在你使用时会作为上下文发送给模型服务商。
它们不会上传到开发者或任何第三方。

### 2.6 输出文件夹授权（本地保存）

如果你启用"写入本地文件夹"功能，扩展会把你选择的文件夹句柄保存在
浏览器的 IndexedDB 中，以便后续写入文件时无需重复选择。
这只是一个指向本地文件夹的引用，不包含文件内容。

## 3. 数据发往何处

**本扩展只有一个数据出口：你自行配置的 AI 模型服务商。**

```
你的浏览器 ──► 你填写的 API 地址（如 https://api.deepseek.com）
```

- 请求由扩展**直接从你的浏览器**发往该地址，不经过任何中转服务器。
- 收据方如何处理数据，取决于**该服务商自己的隐私政策**。
  请你自行查阅所使用服务商的条款。
- 如果你使用本地模型（如 Ollama），数据**不会离开你的电脑**。

默认配置为 DeepSeek 官方接口，但你可以在设置中改成任何兼容
OpenAI 接口协议的服务——包括完全本地运行、不联网的模型。

## 4. 我们如何处理权限

| 权限 | 用途 |
| --- | --- |
| `sidePanel` | 提供扩展主界面（侧边栏） |
| `storage` | 在本地保存设置、记忆、技能、用量 |
| `activeTab` | 在你下达指令时读取并操作当前标签页 |
| `scripting` | 向当前页面注入内容脚本 |
| `tabs` | 获取当前标签页标题与网址（用于判断页面是否可操作、匹配站点技能） |
| `clipboardRead` | 读取剪贴板内容（仅在你点击剪贴板按钮时，用于"总结我复制的东西"） |
| `clipboardWrite` | 把结果写入剪贴板（仅在你要求"复制给我"时） |
| `<all_urls>` | 在任意网页上工作（这是"操作任意网页"的必要条件） |
| `debugger`（**可选**） | 仅当你主动开启「真实输入模式」时才申请 |

**关于 `<all_urls>`**：本扩展需要在任意网站上执行操作（翻译整页、
填写表单、改造样式），因此必须声明此权限。但扩展**不会在后台访问网页**，
所有页面访问都由你在当前对话中明确触发。

**关于 `debugger`（可选权限）**：默认不申请。只有你在设置中主动打开
「真实输入模式」时，浏览器才会弹出授权提示。该模式用于通过浏览器调试协议
派发更真实的输入事件，以兼容少数有反自动化检测的网站。
关闭该模式后权限不再被使用。

## 5. 远程代码

本扩展**不使用任何远程代码**。所有 JavaScript 都包含在安装包内，
不通过 CDN 或网络动态加载、不执行 `eval` 远程脚本。

对 AI 模型的网络请求是**数据请求**（发送文本、接收文本），
不涉及下载或执行代码。

本扩展不包含任何第三方库——全部为原生 JavaScript 实现。

## 6. 数据存储与删除

### 存储位置

| 数据 | 位置 |
| --- | --- |
| 设置、API Key | `chrome.storage.local`（浏览器本地） |
| 记忆、技能、规则、用量 | `chrome.storage.local`（浏览器本地） |
| 输出文件夹授权 | 浏览器 IndexedDB（仅句柄引用） |

**没有任何数据存储在开发者或第三方的服务器上。**

### 如何删除

- **删除单条**：在侧边栏的记忆面板、技能面板中逐条删除
- **清除自动积累的内容**：各面板中点击「清除自动积累的」按钮
- **重置用量统计**：用量面板中点击「全部清零」
- **删除全部数据**：卸载扩展即可彻底清除所有本地数据

扩展没有云端备份，卸载后数据不可恢复。

## 7. 儿童隐私

本扩展不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

---

## 8. 数据安全提示

由于数据由你的浏览器直接发往你选择的模型服务商，请注意：

- **API Key 保存在浏览器本地**。请勿在公用电脑上保存密钥。
- **页面内容会发送给模型服务商**。在使用涉及敏感信息的页面
  （内网系统、含个人隐私的页面）时请谨慎。
- 扩展的系统提示中已明确要求模型**不要记录密码、身份证、银行卡等敏感信息**，
  但 AI 模型并非绝对可靠。处理重要账户页面时，建议在设置中关闭记忆功能。
