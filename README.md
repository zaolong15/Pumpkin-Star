# Pumpkin Star

**一个会自己积累经验的浏览器 AI 智能体。**

它能看懂你正在浏览的网页，并替你操作：点击、填表、翻译、总结、改造页面。
每次任务结束后它会复盘，把可复用的方法存下来，下次同类任务自动用上。

适用于 Edge / Chrome，Manifest V3，**零构建**（原生 JS，加载即用，无 npm 无打包）。

```
你：把这个页面的广告和弹窗去掉，正文放大一点
它：[outline] → 找到 .ad-banner / .sidebar / article
    → [hide] ×2 → [add_style] 注入 CSS → [finish "已净化，正文 18px"]
```

## 快速开始

```bash
git clone <this-repo>
```

1. 打开 `edge://extensions/`（Chrome 用 `chrome://extensions/`）
2. 打开左下角 **开发人员模式**
3. 点 **加载解压缩的扩展**，选择本目录
4. 点工具栏图标（或按 `Alt+J`）打开侧边栏
5. 点右上角 **设置**，填入 API Base URL、API Key、模型名

**兼容任何 OpenAI 接口协议的服务**：DeepSeek、OpenAI、通义千问、Kimi、本地 Ollama 等。
Base URL 填域名即可，`/v1` 会自动补全。模型名可点「获取列表」自动读取。

> API Key 只存在浏览器本地（`chrome.storage.local`），请求直接发往你填的地址，
> 不经过任何第三方中转。

## 它能做什么

| 能力 | 说明 |
| --- | --- |
| **理解页面** | 把 DOM 压成带编号的元素清单；`outline` 还能列出页面结构骨架（页头/正文/侧栏/广告位） |
| **真实操作** | 页面上有可见光标，会移动、悬停、按下、抬起；支持按坐标点击 canvas 等无编号元素 |
| **改造页面** | 像用户脚本一样改当前页面：改文字、隐藏广告、换样式、注入 CSS/JS。**一键撤销**，刷新即还原 |
| **自进化** | 每次任务后自动复盘，积累「技能」与「自我规则」，下次同类任务自动用上 |
| **输出文件** | 结果导出为 md/txt/json/csv，可授权本地文件夹直接写入，也可直接下载 |
| **用量与余额** | 实时 token 统计、花费折算、今日花费；DeepSeek 可读真实余额 |
| **本地记忆** | 记住你的偏好、事实和站点操作经验，全部存本机 |
| **个性化外观** | 中性灰阶（对齐 DeepSeek Harness），可选主题色、深浅模式、圆角、密度、动效 |
| **自定义图标** | 21 个内置图标 + 上传自己的图片，可同步替换浏览器工具栏图标 |
| **附件与剪贴板** | 附加本地文件（文本/代码/图片）作为任务上下文；可读可写系统剪贴板 |
| **对话历史** | 像 DeepSeek 一样保存多段对话，可新建、切换、重命名、删除、搜索 |
| **多标签页** | 可在新标签页打开网址，不打断当前页面 |

## 用法要点

### 附加文件

点输入框左侧的**回形针**按钮选文件。支持：

- **文本类**（md/txt/json/csv/代码等）→ 直接读进上下文
- **图片**（png/jpg/webp/svg）→ 作为视觉输入（需要支持视觉的模型）
- **其它二进制** → 只报告元信息，不读内容

单文件上限 2MB、单次最多 5 个、文本截断至 10 万字符。附加的内容会和你的任务
拼在一起发给模型，发送后自动清空（不会带到下一个任务）。

> 扩展**无法自行读取磁盘** —— 必须由你主动选文件，这是浏览器的硬性限制。

### 剪贴板

- 点输入框左侧的**剪贴板**按钮，可以把剪贴板内容作为上下文（"总结我复制的东西"）
- 让 Agent 输出时也可以说「复制给我」，它会调用 `copy_to_clipboard`

首次读取时浏览器会弹权限提示，允许即可。

### 对话历史

侧边栏顶部的对话按钮可管理历史对话：

- **新建对话**：底部「新对话」按钮，或历史面板里的「＋ 新建对话」
- **切换**：点列表里任意一条即可切回，界面与上下文一起恢复
- **重命名 / 删除**：每行的 ✎ 与 ×
- **搜索**：按标题筛选
- **自动恢复**：重开侧边栏会回到上次的对话

每段对话独立存储，最多保留 50 段、每段 200 条消息。超出时淘汰最旧的。

### 新标签页

让 Agent「新开一个标签页查一下」，它会调用 `new_tab`。
默认会切换过去继续操作；如果只想后台打开，它会传 `focus: false`。

> 由 content script 发起时会转给 background 执行（页面上下文没有开标签页的能力）。

### 速度

做了三处优化，实测数据如下：

| 优化 | 效果 |
| --- | --- |
| **工具预筛** | 按任务意图只给相关工具（只读任务 26 → 8 个）。模型往返是主要耗时，少一次往返就省 4 秒 |
| **鼠标步数** | 移动轨迹 6 步 → 3 步（够触发 hover 逻辑），每次点击省 84ms |
| **条件等待** | 点击/输入/悬停后不再固定等 600ms，改用 MutationObserver 检测页面变化，一动就立刻返回 |
| **并行执行** | 一轮内若全是互不依赖的动作（如同时隐藏三个元素），并行执行而非逐个等待 —— 3 个动作从 1.8s 压到约 0.6s |

综合估算：**只读任务快约 33%**（省掉一次多余往返）；连续点击类任务每次点击快约 40%。
跑 `node tools/perf-test.mjs` 可以看到这些数字的来源。

## 三个值得一看的设计

### 1. 改造页面靠「看得见结构」，不是猜选择器

早期版本「改页面没效果」，根因是模型拿不到可改造元素的编号 ——
`snapshot` 只收**可交互元素**（按钮/链接/输入框），而广告容器、侧边栏、正文主体
是**结构性元素**，`read_page` 也只给纯文本不给结构。

于是加了 `outline`：列出页面区块骨架，每个区块带编号、真实 class、面积占比、是否首屏。
模型照着真实 class 写 CSS，而不是凭空猜。

### 2. 自进化：执行 → 复盘 → 提炼 → 注入

任务结束后自动复盘这一次的执行过程，产出两类内容：

- **技能**：某类任务怎么做（带触发条件，匹配时才注入）
- **自我规则**：自己该注意什么（带置信度，反复出现会提升）

技能匹配用**停用词过滤 + 双向覆盖率**，避免中文按字切分时
「翻译这个页面」误命中「去广告」（实测得分从 0.408 降到 0.000）。
站点专属技能**硬性排除**异站，防止跨站泄漏。

全部内容可在顶栏面板里查看、修改、删除、手动添加 —— 不是黑盒。

### 3. 界面状态不靠「展示」靠「可用性」

曾经有一条「处理中」运行状态条，反复出现「任务已结束但界面仍显示处理中」。
根因是**「要展示的状态」和「真实状态」是两份数据**，任何异常路径没同步上就卡住，
而且卡住之后连停止键都会失效。

现在的做法是运行中不做文字提示，只改两个控件的可用性（发送键置灰、停止键点亮）。
即使偶尔没复位，也不会有假提示挂在那里骗人，停止键一点就恢复。

## 项目结构

```
pumpkin-star/
├── manifest.json              # MV3 清单
├── icons/                     # 图标（矢量绘制脚本生成）
├── src/
│   ├── background.js          # service worker：标签页、API 代理、余额、自进化路由
│   ├── shared/
│   │   ├── messages.js        # 消息协议 + 默认设置 + 色板
│   │   ├── memory.js          # 记忆库
│   │   ├── skills.js          # 自进化·技能（匹配算法）
│   │   ├── evolution.js       # 自进化·规则
│   │   ├── conversations.js   # 对话历史存储
│   │   └── usage.js           # token 统计、费用、余额
│   ├── content/
│   │   ├── content.js         # 页面代理：snapshot/outline/act/鼠标控制
│   │   └── floating.js        # 页面悬浮窗（可选，默认关闭）
│   └── panel/
│       ├── panel.{html,css,js}  # 侧边栏界面
│       ├── agent.js           # 智能体循环 + 工具定义与预筛
│       ├── icons.js           # 内置图标库
│       ├── files.js           # 文件输出
│       └── upload.js          # 本地文件读取
└── tools/                     # 测试与图标生成
```

### 数据流

```
侧边栏 ── runAgent(task) ──▶ agent.js ──▶ background.js ──▶ 模型 API
                                │              │
                                │              ├─▶ memory / skills / rules 注入
                                │              └─▶ usage 统计
                                ▼
                        content.js ──▶ 操作 DOM ──▶ 网页
```

### 测试是怎么写的

不是「跑一遍不报错」，而是**手搓替身把真实代码跑起来**：

- `patch-test.mjs` 实现了一个迷你 DOM，把 `content.js` 放进去真跑，
  逐条核对点击派发的事件顺序、坐标是否正确、`click_at` 是否真的命中目标
- `files-test.mjs` 用 `../../etc/passwd`、`C:\Windows\x.md` 等载荷验证路径穿越防护
- `theme-test.mjs` 用真实的 Oklab→sRGB 转换算 `oklch()` 对比度
- `evolution-test.mjs` 实测分数分布来确定匹配阈值，而不是拍脑袋

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `sidePanel` | 侧边栏界面 |
| `storage` | 本地保存设置、记忆、技能、用量 |
| `activeTab` / `scripting` / `tabs` | 读取并操作当前页面 |
| `clipboardRead` / `clipboardWrite` | 读写剪贴板（仅在你主动点击或要求时） |
| `<all_urls>` | 在任意网页上工作 |
| `debugger`（**可选**） | 仅当你在设置里开启「真实输入模式」时才申请 |

文件写入用 File System Access API，下载用 Blob URL，**都不需要额外权限**。

## 已知限制

- **不能操作系统鼠标键盘**。浏览器扩展没有这个 API —— 那是 pyautogui 一类本地程序的事。
  这里所有操作都是页面内派发事件模拟的。合成事件 `isTrusted=false`，
  少数风控严格的网站可能不响应；可在设置里开启「真实输入模式（CDP）」，代价是
  需要 `debugger` 权限且页面顶部会出现调试横幅。
- 无法操作 iframe 内的元素（content script 仅注入顶层文档）。
- 无法处理验证码、滑块、扫码登录等反自动化机制。
- 页面正文超长时截断至 20000 字符、最多列出 150 个交互元素。
- 改造只能影响 DOM 与样式，改变不了页面的网络请求或 CSP 策略。
- 撤销依赖内存中记录的原始状态，刷新页面后无法再撤销（改动本身也一并消失）。

## 排查

| 现象 | 处理 |
| --- | --- |
| 「无法连接页面脚本」 | 页面在安装扩展前就打开了，刷新页面 |
| 「浏览器内置页面不允许操作」 | 切到普通 http/https 网页 |
| 「API Key 无效」 | 检查 Key 是否过期 |
| 「模型名或 Base URL 不对」 | 点「获取列表」核对模型名 |
| 点击没反应 | 元素可能在 iframe 内；或网站有风控，试试「真实输入模式」 |
| 改造没效果 | 让它先用 `outline` 看结构，再用真实 class 写 CSS |
| 点「停止」没反应 | 按 Esc，或刷新侧边栏 |
